# 检测结果说明

本目录包含使用 YOLOv8 模型对 SKU110K 数据集进行零售货架商品检测的结果文件。下面详细介绍各类结果文件的内容和用途。

## 性能评估文件

### 混淆矩阵

- **confusion_matrix.png**: 显示模型在验证集上的性能矩阵，包括真正例(TP)、假正例(FP)、假负例(FN)等。
- **confusion_matrix_normalized.png**: 归一化的混淆矩阵，更好地反映不同类别的性能比例。

### 精度-召回率曲线

- **PR_curve.png**: 精度-召回率曲线，展示不同阈值下模型的精度和召回率变化。
- **P_curve.png**: 精度曲线，展示不同置信度阈值下的精度变化。
- **R_curve.png**: 召回率曲线，展示不同置信度阈值下的召回率变化。
- **F1_curve.png**: F1 分数曲线，展示不同置信度阈值下精度和召回率的平衡点。

### 数值结果

- **results.csv**: 包含模型评估的详细数值结果，包括各类 mAP 指标、精度、召回率等。

## 可视化结果

### 验证批次预测结果

- **val_batch\*\_pred.jpg**: 模型在验证集批次上的预测结果可视化，显示预测的边界框和置信度。
- **val_batch\*\_labels.jpg**: 验证集批次上的真实标签可视化，显示真实的边界框。

### 训练批次预测结果

- **train_batch\*.jpg**: 训练过程中不同批次的模型输入和预测结果可视化。
- 文件名中的数字表示训练批次索引，较大的数字通常对应训练后期的批次。

### 主要预测结果

- **predictions.png**: 模型在测试集代表性图像上的预测结果，以网格排列方式展示多个样本。

## 标签分析

- **labels.jpg**: 数据集标签的分布可视化，包括目标数量、尺寸分布等。
- **labels_correlogram.jpg**: 标签相关性分析，展示不同特征之间的相关关系。

## 模型配置

- **args.yaml**: 训练和评估过程中使用的参数配置，包含批次大小、学习率等。

## 结果分析

在 SKU110K 数据集上，YOLOv8 模型达到了以下性能：

- **mAP50-95**: 0.5226
- **mAP50**: 0.8587
- **mAP75**: 0.5767
- **精确率**: 0.8740
- **召回率**: 0.7787

从结果图像可以观察到以下特点：

1. **检测优势**:

   - 模型能成功识别大多数清晰可见的商品
   - 能很好处理不同尺寸的商品
   - 在各种光照条件下表现稳定

2. **挑战情况**:
   - 高度重叠的商品可能被漏检
   - 极小的商品识别率较低
   - 相似外观的商品可能造成混淆

此检测系统在零售场景中有广泛应用，包括自动化库存管理、货架监控和商品排列优化等场景。

## 应用场景

这些检测结果展示了该系统在以下零售场景中的应用潜力：

- 库存管理与盘点
- 商品陈列合规性检查
- 购物体验优化
- 自动结账系统

## 进一步改进方向

基于当前结果，可以考虑以下改进：

- 增加针对小目标的训练策略
- 优化 NMS 算法以更好处理重叠商品
- 增加数据增强以提高对不同光照条件的适应性
