# 检测结果说明

本目录包含使用 YOLOv8 模型对 SKU110K 数据集进行零售货架商品检测的结果文件。下面详细介绍各类结果文件的内容和用途。

## 性能评估文件

### 混淆矩阵

- **confusion_matrix_normalized.png**: 归一化的混淆矩阵，更好地反映不同类别的性能比例。

### 精度-召回率曲线

- **PR_curve.png**: 精度-召回率曲线，展示不同阈值下模型的精度和召回率变化。
- **F1_curve.png**: F1 分数曲线，展示不同置信度阈值下精度和召回率的平衡点。

### 数值结果

- **results.csv**: 包含模型评估的详细数值结果，包括各类 mAP 指标、精度、召回率等。

## 可视化结果

### 验证批次预测结果

- **val_batch\*\_pred.jpg**: 模型在验证集批次上的预测结果可视化，显示预测的边界框和置信度。
- **val_batch\*\_labels.jpg**: 验证集批次上的真实标签可视化，显示真实的边界框。

## 模型配置

- **args.yaml**: 训练和评估过程中使用的参数配置，包含批次大小、学习率等。

## 结果分析

在 SKU110K 数据集上，YOLOv8 模型达到了以下性能：

- **mAP50-95**: 0.5226
- **mAP50**: 0.8587
- **mAP75**: 0.5767
- **精确率**: 0.8740
- **召回率**: 0.7787

从结果图像可以观察到以下特点：

1. **检测优势**:

   - 模型能成功识别大多数清晰可见的商品
   - 能很好处理不同尺寸的商品
   - 在各种光照条件下表现稳定

2. **挑战情况**:
   - 高度重叠的商品可能被漏检
   - 极小的商品识别率较低
   - 相似外观的商品可能造成混淆
